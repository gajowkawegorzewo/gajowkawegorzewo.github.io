➕ Dodaj nowy blok

📋 Istniejące ręczne bloki

Po dodaniu/usunięciu workflow GitHub Actions regeneruje availability.json w ~30 sekund.

ℹ️ Jak to działa

  1. Airbnb iCal jest pobierany automatycznie co kilka godzin przez workflow sync-ical.yml.
  2. Ręczne bloki (Booking, telefon, etc.) wpisujesz tutaj — zapisują się do availability/manual-blocks.json.
  3. Po zapisie GitHub Actions wykrywa zmianę i regeneruje availability.json (sumę wszystkich źródeł).
  4. Date picker na stronie głównej blokuje wszystkie te terminy.
